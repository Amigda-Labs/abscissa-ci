# Example Floor Plans

Draft-only rectilinear floor plan images for Abscissa CI measurement training
and evaluation. Images show dimensions in meters and do not include computed
answers.

## Layout

- `training/images/` - images intended for model or workflow training.
- `tests/images/` - held-out images for evaluation runs.
- `json/manifests/` - dataset and split manifests generated by
  `generate_floor_plans.py`.
- `json/inputs/` - structured sample input JSON files.
- `json/tile_estimates/` - generated tile-estimate JSON outputs.
- `reports/tile_estimates/` - generated tile-estimate Markdown reports.

## Regeneration

Run this from the repo root:

```bash
python3 example_floor_plans/generate_floor_plans.py
```

The generator writes images into the correct split folders and refreshes the
manifest JSON files.

## Review Status

All generated construction references are drafts for human review. Do not treat
them as final estimates, installation instructions, engineering approval, or
code-compliance documentation.
