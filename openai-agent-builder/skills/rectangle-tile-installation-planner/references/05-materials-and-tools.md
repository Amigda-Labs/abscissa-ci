# Step 5: Gather Materials And Tools Needed

## Goal

List the materials and tools needed for a basic floor tile installation plan.

## Materials Rules

- Include tile quantity from step 2.
- Do not invent mortar, grout, membrane, primer, or sealer quantities.
- Mark unknown product-specific quantities as `Verify`.
- Flag wet areas, exterior areas, large-format tile, natural stone, movement
  joints, and substrate correction as review items.

## Materials Checklist

| Item | Status | Why Needed | Notes / Verify |
| --- | --- | --- | --- |
| Floor tiles | Required | Main finish material | Use computed `order_tile_count`. |
| Setting mortar or adhesive | Verify | Bonds tile to substrate | Must match tile, substrate, exposure, and manufacturer instructions. |
| Grout | Required | Fills tile joints | Verify grout type and joint width. |
| Tile spacers or leveling clips | Required | Controls joints and alignment | Leveling clips are more important for larger tile. |
| Movement joint sealant/profile | Verify | Handles movement at perimeters and required joints | Installer must confirm locations. |
| Primer/patch/self-leveler | Conditional | Substrate correction | Only if substrate needs it or product system requires it. |
| Waterproofing/crack-isolation/uncoupling membrane | Conditional | Required for some wet, exterior, cracked, or movement-prone assemblies | Do not assume unless scope requires it. |
| Edge trims/transitions | Verify | Finish exposed edges and transitions | Confirm adjacent floor finishes and doorways. |
| Clean water and cleanup materials | Required | Mixing and cleanup | Follow product data sheets. |

## Tools Checklist

| Tool | Status | Why Needed | Notes / Verify |
| --- | --- | --- | --- |
| Tape measure, pencil, square, level/straightedge | Required | Measurement and layout | Use for layout checks before setting. |
| Chalk line or laser level | Strongly recommended | Keeps layout straight | Useful for larger rooms. |
| Buckets and margin trowel | Required | Mixing and handling material | Use clean containers. |
| Notched trowel | Required | Applies mortar correctly | Trowel size depends on tile and mortar. |
| Tile cutter or wet saw | Required | Cuts perimeter and detail pieces | Wet saw is preferred for porcelain, stone, and dense tile. |
| Spacers or leveling system | Required | Maintains consistent joints | Select based on tile and layout. |
| Rubber grout float | Required | Applies grout | Match grout type. |
| Sponge, wash bucket, cloths | Required | Cleanup | Needed during and after grouting. |
| PPE: eye protection, gloves, knee pads | Required | Worker protection | Add hearing/respiratory protection for cutting or dust. |
| HEPA vacuum or wet dust control | Conditional | Dust control | Important for silica-containing materials. |

## Output Rule

Keep materials and tools in table form so the user can quickly review what is
required, conditional, and still needs verification.
